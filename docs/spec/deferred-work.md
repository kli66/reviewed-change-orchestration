# Deferred work

This register holds forward-looking owner work that is not active or on the first dogfood critical path. When a trigger fires, promote the entry into a newly reconciled `docs/changes/<name>/` artifact and strike the entry from this register.

## Validation evidence and environment readiness

**Trigger:** A separately accepted enhancement to the repository's one-item orchestration requires reusable validation-evidence assessment or environment-readiness records beyond the opaque evidence references already supported by the v0 envelopes.

Re-propose only after reconciling the implementation boundary with `personal-pi` controller ownership, selecting Python 3.12+ or an explicitly separate compatibility environment, and completing a split-versus-atomic acceptance-feasibility review. The prior detailed proposal remains available in Git history as `docs/changes/deepen-evidence-and-readiness/change.md` at `d2514e6`.

## Review-bound accept and execute

**Trigger:** The accepted `doc-contract` interface exposes a versioned content-free acceptance plan and apply-time expected-plan enforcement, and post-dogfood evidence demonstrates that combined provisional acceptance and execution is preferable to the existing accepted-only workflow.

Re-propose as optional owner-local workflow work, not as a prerequisite for the four-envelope dogfood or `personal-pi` controller. Reconcile it against the then-current evidence interface and authority contract. The prior detailed proposal remains available in Git history as `docs/changes/integrate-planned-accept-and-execute/change.md` at `d2514e6`.
